# Практическая работа №3 — Activity и Intent

[← Все задания курса](../../README.md)

В приложении есть два экрана на Kotlin и Jetpack Compose. На главном экране можно ввести текст, открыть вторую Activity с этим текстом, передать номер в приложение телефона или поделиться текстом через системное меню.

## Реализовано

- Передача строки между Activity через explicit Intent.
- Проверка пустого ввода и номера телефона.
- Набор номера через `ACTION_DIAL`.
- Отправка текста через `ACTION_SEND` и системный chooser.

## Запуск и проверка

Открой корень репозитория в Android Studio и выбери модуль `homework-03`.

```powershell
.\gradlew.bat :homework-03:assembleDebug
.\gradlew.bat :homework-03:testDebugUnitTest :homework-03:lintDebug
```

## Самопроверка

- [ ] Вторая Activity отображает введённый текст.
- [ ] Пустой текст не открывает вторую Activity.
- [ ] Кнопка звонка открывает экран набора номера, не совершая вызов.
- [ ] Кнопка «Поделиться» передаёт текст в системное меню.
