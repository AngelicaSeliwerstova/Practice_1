# Исходное приложение `Practice_1`

[← Все задания курса](../../README.md)

Исходный Android-модуль, сохранённый из корневого приложения репозитория `Practice_1` при переносе работ в структуру учебного курса. Код и ресурсы оставлены без изменений.

## Запуск и проверка

Открой корень репозитория в Android Studio и выбери модуль `homework-01`.

```powershell
.\gradlew.bat :homework-01:assembleDebug
.\gradlew.bat :homework-01:testDebugUnitTest
.\gradlew.bat :homework-01:lintDebug
```
